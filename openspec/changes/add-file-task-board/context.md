## Waiver classification

A waiver is valid only when direct execution will occur and ROSE records it before execution with exact evidence. Allowed classes are: user supplied complete bounded evidence makes dispatch redundant; selected role is unavailable but ROSE has equivalent lawful tools/permission/scope; or concrete measured dispatch cost exceeds added evidence value. Dependency not ready, overlap requiring package split, changed scope, cancellation, invalid selector, or specialist-only capability absence is not a direct waiver; it leaves the package pending/blocked/cancelled or requires DEFINE revision. If accepted evidence from another package already satisfies the exact scope, ROSE cancels the duplicate as `superseded` and records the covering evidence instead of claiming a direct-execution waiver.
