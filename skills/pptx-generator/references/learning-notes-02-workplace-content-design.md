### Lesson 01 — Emergency Workflow: Turn a Word Document into Slides in Four Steps

#### Adjust the Hierarchy

- Open `View > Outline` and adjust the information hierarchy there. Do not use body-text levels as the structural hierarchy.

#### Three-Step SmartArt Layout Method

1. Transform the text hierarchy.
2. Choose a logical graphic.
3. Improve the graphic by changing its colors and dimensions and correcting alignment.

### Lesson 02 — Content Writing: Create a Presentation Script with Clear Priorities

1. Define the audience: identify who will hear the presentation, because different viewpoints lead to different content expectations.
2. Structure the content through a question-and-answer method.
3. Organize scattered information with a claim-and-evidence method.

### Lesson 03 — Information Synthesis: Give Unstructured Information a Structure

#### Synthesize Information

1. **Element method:** ask, “Which aspects or elements does this information contain?” Some elements need to be grouped by shared characteristics.
2. **Model method:** use a problem-analysis framework, for example `A + B = C`.
3. **Process method:** organize information in chronological or procedural order.

#### Extract the Key Point

1. Use induction to identify common actions, outcomes, scenarios, or other shared properties.
2. Phrase a conclusion as `verb + adjective + noun` when that pattern fits.
3. Look for keywords and for information placed at the beginning or end.

### Lesson 04 — Visual Expression: Make Abstract Content Easier to Understand

#### Make It Concrete

1. Extract the concept's defining characteristics.
2. Associate those characteristics with a user scenario.
3. Rephrase the idea from the user's point of view.

#### Use an Analogy

1. Extract the concept's defining characteristics.
2. Find a familiar object with similar characteristics.
3. Rephrase the idea to show the similarity.

Useful sentence patterns include:

- “equivalent to …”
- “the … of its field”
- “an online version of …”
- “China's …”

### Lesson 05 — Create a Refined Color Scheme in Three Steps

[FRAME] The source formula aims for clear priority and visual harmony.

#### When Color Planning Is Needed

1. A chart has multiple series.
2. A page has multiple content sections.
3. A page looks visually flat.

#### PowerPoint Color-Planning Workflow

##### Choose the Main Color

1. Sample a brand or logo color.
2. Search for vector-style imagery and sample its dominant color.
3. Choose a color by the emotional character associated with the intended style.

Source-note reference: [58pic color reference](https://www.58pic.com/peisebiao#ps11). `[UNVERIFIED]` Availability, licensing, and current content were not checked during this translation.

##### Add Analogous Colors with the Cross-Axis Method

1. Keep the overall hue family coherent.
2. Convert RGB values to HSL and keep adjacent hue shifts around `15–30°`.
3. Keep the full hue span within about `60°`.
4. Remember that RGB channels use `0–255`, not `0–100`.

##### Separate Hierarchy with Light and Dark Variants

1. On a dark base, combine dark color, white, and a light variant.
2. On a light base, combine light color, black, and a dark variant.

Ways to create lightness levels:

1. Adjust transparency.
2. Adjust color brightness without pushing it to the extreme.
3. Use a color-scale generator when allowed. The source note names [Eva Design System](https://colors.eva.design/). `[UNVERIFIED]` Availability, licensing, and current behavior were not checked during this translation.

### Lesson 06 — Font Selection Beyond Microsoft YaHei

#### Three Font Roles in a Typical Deck

1. Cover or quotation font: a distinctive display face.
2. Title font: a sans-serif, serif, or regular-script family.
3. Body font: a readable sans-serif, serif, or regular-script family.

#### Font-Pairing Workflow

1. Define the style.
2. Install or verify the fonts.
3. Find compatible pairings.
4. Establish the deck's font scheme.

**Visual description — font personality matrix:** A four-quadrant chart maps font character along two axes. The horizontal axis runs from thin strokes to thick strokes, and the vertical axis runs from rounded strokes to sharp strokes. Bubbles place use cases such as elegant, feminine, business, formal, industrial machinery, racing, cartoon, pets, and strength in the corresponding regions. Corner callouts list representative font categories.

#### Font Characteristics

1. Thicker strokes feel more powerful; thinner strokes feel lighter.
2. More complex strokes feel more stylized; simpler strokes feel more businesslike.
3. Sharper strokes feel more aggressive; rounder strokes feel softer.

#### Pairing Principles

1. Use contrast: Bold or Heavy for titles and Regular for body text.
2. Preserve readability.

For Chinese-and-English pairings, match:

1. stroke weight;
2. cap/character height;
3. overall width or visual mass;
4. stylistic character.

When replacing fonts in mixed Chinese-English text, select the text box, apply the Chinese font first, and then apply the English font to the Latin characters.

#### Calligraphic Fonts

- Use an online vector calligraphy reference when appropriate. The source note names [shufaziti.com](http://www.shufaziti.com/). `[UNVERIFIED]` Availability, licensing, and current content were not checked during this translation.
- Lay out calligraphic text by splitting it, arranging it, and then adjusting scale.

Three common height rhythms:

1. high–low–low–high;
2. low–high–high–low;
3. high–low–high–low.

### Lesson 07 — Three Background-Treatment Methods

#### Background Workflow

1. Search for a background.
2. Filter the candidates.
3. Process the selected background.

Choose images with abundant negative space and few competing elements. Match the subject and reinforce the intended style. The source note names [Freepik](https://www.freepik.com/) as one search source. `[UNVERIFIED]` Asset licensing and current availability must be checked before use.

#### Gradient-Mask Method

1. Add a semi-transparent gradient mask.
2. Adjust the image saturation.
3. Correct the layer order.
4. On a dark image, use the darker region; on a light image, use the lighter region.
5. Point the gradient along the direction of the visual obstacle in the image.

#### Washout Method

1. Use this method to turn a multicolored image into a pale, near-white background.
2. Reduce saturation.
3. Apply a washout effect.
4. Overlay a semi-transparent shape mask.

#### Sky-Replacement Method

1. Remove the background while keeping the main subject.
2. Find a sky image with a similar color tone.
3. Composite the images. If the sky is not wide enough, extend it with a color block and a gradient from `100%` transparency to `0%`, using a color close to the background such as white or gray.
4. Let the sky occupy about two-thirds of the frame and the subject one-third; place text around the centerline of the sky region.

### Lesson 08 — Shape-Based Creative Treatments

#### Three Uses of Shapes

- The source note records this heading and develops the uses through masking, image-shape blending, and visual layering below.

#### Use Occlusion as a Mask

- For a light theme, use a light variant of the main color.
- For a dark theme, use a dark variant of the main color.

For a local mask:

1. combine a linear gradient with stop-transparency adjustments;
2. combine a radial gradient with softened edges.

#### Blend Images with Shapes

1. Use an occluding element as a mask and match it to the lower color block.
2. Blend the image into the shape.
3. Add depth so the page does not feel flat.

Use color blocks to distinguish information structure. Keep light-dark pairing deliberate: dark plus light, or color plus gray/white.

### Lesson 09 — Use Images to Increase Visual Impact

#### Image Libraries

#### Image Search

1. Extract a keyword, such as “Sichuan,” “good experience,” or “welcoming a challenge.”
2. Add an associated idea, such as “Shu embroidery,” “Leshan Giant Buddha,” “smile,” or “surfing.”
3. Add constraints such as asset type (`PNG`, `2.5D`), camera angle (top-down, front view), or subject characteristics (Chinese person, sunset).

#### Image Selection

Check:

1. Is there enough negative space?
2. Does the subject match the message?
3. Is the style consistent with the other images?
4. Is the composition visually balanced?

#### Image Processing

1. Scale to emphasize the subject and rebalance the frame.
2. Flip symmetrically to correct visual imbalance or extend the composition.
3. Slice and stretch only suitable flat-color regions when the image is not wide enough.
4. Recolor vector artwork to keep the deck's palette coherent.

### Lesson 10 — Icon Use Guide

#### When to Use Icons

1. A slide contains only text.
2. A slide feels too empty.

#### Icon Categories

1. General-purpose icons.
2. Monochrome icons.
3. 3D icons.

#### Six Style-Consistency Checks

1. Corner radius.
2. Complexity.
3. Stroke weight.
4. Monochrome versus multicolor.
5. Supporting-container style.
6. Filled versus outlined construction.

Prefer SVG when possible.

#### Icon Processing

1. **Gradient treatment:** convert an SVG into editable PowerPoint shapes by ungrouping twice, then apply colors from the theme or a local fade.
2. **Local accent color:** separate the icon and recolor selected strokes; Boolean Fragment can help split the artwork.
3. **Supporting block:** add a consistent shape beneath the icon.

### Lesson 11 — Six Common Layout Mistakes

1. **Text columns are too wide:** keep a paragraph column around one-half or one-third of the slide width.
2. **Weak hierarchy:** strengthen contrast between primary and secondary information.
3. **Unclear structure:** identify relationships and group information by dimension.
4. **Missing alignment:** select an alignment method that follows the layout.
5. **Inconsistent pages:** use a consistent content area.
6. **Insufficient whitespace:** leave room for the content to breathe; the note recommends at least the width of one or two characters.

#### Contrast

[FRAME] Contrast separates information levels.

Methods:

1. bold text;
2. change color;
3. enlarge type by `1×`, `1.5×`, or `2×`;
4. add a color block;
5. add a line;
6. contrast solid and transparent treatments.

**Visual description — six contrast methods:** Six dark cards are arranged in a two-by-three grid. Each card shows the same title-and-body module altered by one method: bold title, orange title, enlarged title, orange title capsule, underline, or faded/transparent title. Because the content is held constant, the visual isolates the effect of each contrast technique.

#### Alignment

[FRAME] Alignment makes information appear orderly.

- Linear alignment covers left, right, center, and matrix alignment of individual elements.
- Area alignment covers the whole page, including guide-based and visually weighted symmetrical layouts.
- Do not indent paragraphs with two blank spaces.

#### Proximity

[FRAME] Physical closeness communicates a relationship.

Methods:

1. adjust spacing;
2. use color blocks or lines;
3. mark groups with different colors;
4. keep inner spacing smaller than outer spacing;
5. keep spacing consistent within the same hierarchy level.

#### Repetition

[FRAME] Repetition creates consistency by retaining visual similarity for content with the same meaning or role.

### Lesson 12 — A Three-Step Universal Layout Method

[FRAME] The method aims to make the information structure clear, highlight the key point, and support rapid scanning.

#### Organize the Structure and Determine the Layout

Identify the meaning of each module and derive the layout from the relationships between modules.

Use the trunk-and-branches method: identify the main line first, then the branches.

Common structures:

1. argument;
2. containment;
3. process.

#### Organize Hierarchy and Highlight the Focus

Prioritize important numbers, achievements, and titles. Change hierarchy through:

1. type size;
2. color;
3. weight;
4. typeface;
5. a supporting background;
6. solid-versus-transparent treatment.

#### Understand the Information and Visualize It

1. Visualize information with icons or images.
2. Visualize data.
3. Visualize logic with lists, processes, cycles, hierarchies, relationships, matrices, or pyramids.

### Lesson 13 — Four Alternatives to a Plain Parallel Layout

#### Centered Surround Layout

1. Add hierarchy through scale, color, solid/transparent contrast, and depth.
2. Add icons.
3. For an odd number of sections, use a half-ring arrangement.

#### Fan Layout

- To convert a chart into shapes, use `Home > Paste > Paste Special > Enhanced Metafile`, and then ungroup it as needed.

#### Perspective Layout

1. Keep upper and lower curves consistent.
2. Use Boolean Subtract.
3. Press `F4` to repeat the previous operation.

#### Card Layout

1. Keep gaps consistent and use smart guides while aligning shapes.
2. Alternate the main color with black or gray.
3. Keep the shape language consistent, including corner radii.

If the page feels too empty, add a meaningful number, icon, or image rather than arbitrary decoration.
