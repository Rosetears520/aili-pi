## Beginner Training Camp L1

### Lesson 01 — A Four-Step Formula for a Creative Cover

#### Cover Formula

`Cover design = information layout + background asset + content placement + mask`

1. **Information layout**
   - Increase contrast to separate primary and secondary information.
   - Use bold weight, changed color, or a different typeface.
2. **Background asset**
   - Choose an image with semantic relevance.
   - Evaluate its composition.
3. **Content placement**
   - Reliable starting positions include a centered layout and a left-aligned layout that follows normal reading order.
4. **Mask**
   - Add a semi-transparent color block.
   - Reduce interference from the image.
   - Choose color and transparency deliberately.
   - Sample a dark tone from the image for the mask.
   - The note recommends roughly `30–50%` transparency.

**Visual description — cover formula:** A dark instructional graphic organizes cover decisions into four rows. “Information layout” offers bold title, changed title color, or changed typeface. “Background asset” branches into semantic relevance and composition. “Content placement” offers left-aligned, centered, or an image-led negative-space layout. “Mask” offers full-slide and half-slide treatments. Thin lines connect the rows and a warm glow at the bottom provides an example of visual atmosphere.

#### Calligraphic Text Layout

1. Split the text into individual units.
2. Find a reference composition.
3. Arrange the units with deliberate stagger.
4. Add English text in suitable empty space.
5. Prevent strokes from overlapping each other.

### Lesson 03 — A Three-Element Timeline Formula

#### Timeline Formula

`Timeline = axis design + node design + information layout`

1. **Axis:** straight line, curve, irregular line, or a real-world visual element.
2. **Node:** style endpoints with shape or arrowhead options.
3. **Information:** time, event, and description; emphasize either the time or the event.

**Visual description — timeline matrix:** A dark three-row graphic presents four axis choices—straight, curved, irregular, and physical-object based—three node choices—endpoint, icon, and line-based—and three information roles—time, event, and description. Each option appears in a thin outlined circle aligned to a grid.

#### Creative Use of the Curve Tool

- A larger distance between two points produces a gentler curve.
- Connect the start and end points to create a closed shape.

### Lesson 04 — A Three-Step Table Formula

#### Table Formula

`Table = choose style + unify alignment + separate hierarchy`

1. Choose among:
   - a color-block table;
   - a three-line table with disciplined cell spacing and strict alignment;
   - a card table that groups content by a meaningful dimension and adds supporting blocks.
2. Left-align long text. Right-align numbers and use consistent decimal places.

#### Slanted Layout

- Draw a guide along the edge of a parallelogram and align the elements to that slope. Tweening tools can accelerate repeated placement.

#### Map Assets

- Vector maps: use an authoritative national map service or a reputable map provider.
- 2D maps: use a mapping platform.
- Satellite maps: use an appropriate earth-imagery source.

#### Background Treatment

- Reduce brightness to darken a background image as a whole.

### Lesson 05 — A Three-Step Image-Layout Formula

#### Image Formula

`Image layout = match the content area + unify spacing + unify treatment`

Treatments may include outlines, styles, color tone, 3D rotation, shadows, or reflections.

1. Establish the content area by inserting a full-slide rectangle, scaling it proportionally, using copies at the lower-left and lower-right, and adding guides.
2. For an image wall, select all images, give them consistent dimensions, and arrange them in a matrix.

#### Correct Image Recoloring

[FRAME] The goal is a unified tone and coherent style.

1. **Make an image transparent:** adjust transparency or set saturation to `0`. One workflow is to insert the image, place an equal-size color block over it, cut/copy as needed, and use picture fill.
2. **Place a shape behind the image:** insert an equal-size color block, adjust its gradient, and move it beneath the image.

#### 3D Rotation Guide

Use 3D rotation to create spatial depth. Control:

1. the rotation preset;
2. the light source and resulting light/dark regions;
3. the depth or extrusion.

### Lesson 06 — A Four-Step Formula for Large Amounts of Text

#### Text Formula

`Text layout = divide into blocks + change hierarchy + visualize information + adjust spacing`

1. Group related content to make the structure visible.
2. Treat titles and numbers as likely focal information.
3. Match line spacing to size and stroke weight:
   - larger/heavier type needs tighter spacing;
   - smaller/lighter type needs more spacing, around `1.2–1.3×` in the note.
4. For paragraphs longer than three lines, use justified alignment in the noted treatment.
5. Avoid a short orphaned tail.

### Lesson 07 — A Formula for Creative Layouts

#### Creative-Layout Formula

`Creative layout = determine geometry + draw visual forms + change hierarchy + apply symmetry`

1. Determine geometry from the odd/even number of sections: use a full ring or half ring.
2. Draw forms such as vector shapes, real-world metaphors, or moving-image assets.
3. Change hierarchy through contrast, such as color block plus outline or color block plus transparent block.
4. Apply vertical or horizontal symmetry where it supports the composition.

**Visual description — creative-layout formula:** A dark four-row diagram presents the decision chain. The first row chooses full-ring or half-ring geometry. The second chooses vector shape, real-world metaphor, or motion visual. The third chooses text or graphic hierarchy. The final row chooses vertical or horizontal symmetry. Orange labels identify the preferred examples.

#### Creative Ring Charts

1. Use the ring to show a proportion.
2. The ring dimensions determine its thickness.
3. For text around the ring, match the text-box dimensions to the chart dimensions.
